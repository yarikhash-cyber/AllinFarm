# Вікі AllinFarm

Тут лежатимуть агрономічні норми і статті: Markdown з YAML-шапкою, кожна норма з діапазоном, одиницею, умовами і джерелом з DOI. Формат і автоматичну перевірку норм додає крок плану «Формат норми».

Агрономічні норми беремо з наукових досліджень, підручників і даних оригінаторів. Українські державні агрономічні нормативи не використовуємо; державні документи лише для законів.
