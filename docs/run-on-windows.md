# Запуск AllinFarm на Windows

Ця інструкція потрібна один раз. Далі запуск = подвійний клік на `start.cmd`.

Що знадобиться: Windows 10 (версія 22H2) або Windows 11, 64-розрядна; щонайменше 8 ГБ оперативної пам'яті (краще 16 ГБ); близько 15 ГБ вільного місця на диску C.

Як перевірити: **Пуск → Параметри → Система → Про систему**. Там видно «Тип системи» (має бути 64-розрядна) та обсяг пам'яті.

## 1. Встановити Docker Desktop

Docker Desktop запускає всю систему AllinFarm у «контейнерах»: базу, API і сайт. Нічого окремо налаштовувати не треба.

1. Відкрийте <https://www.docker.com/products/docker-desktop/>.
2. Натисніть **Download Docker Desktop**, далі **Download for Windows – AMD64**. Якщо у вас процесор Snapdragon, оберіть **ARM64**.
3. Запустіть завантажений файл `Docker Desktop Installer.exe`. На питання «Дозволити цій програмі вносити зміни?» натисніть **Так**.
4. У вікні **Configuration** залиште позначку **Use WSL 2 instead of Hyper-V** і натисніть **OK**.
5. Коли з'явиться **Installation succeeded**, натисніть **Close and restart**. Комп'ютер перезавантажиться.
6. Після перезавантаження Docker Desktop відкриється сам. Натисніть **Accept**, щоб прийняти умови.
7. Вхід в обліковий запис Docker не потрібен: натисніть **Skip** або **Continue without signing in**. Опитування теж можна пропустити (**Skip**).
8. Якщо з'явиться чорне вікно з проханням оновити WSL, натисніть будь-яку клавішу і дочекайтеся кінця оновлення.
9. Дочекайтеся, поки внизу зліва у вікні Docker Desktop з'явиться зелений напис **Engine running**.

## 2. Встановити GitHub Desktop

GitHub Desktop завантажує код проєкту і потім оновлює його одною кнопкою.

1. Відкрийте <https://desktop.github.com/> і натисніть **Download for Windows**.
2. Запустіть завантажений файл `GitHubDesktopSetup-x64.exe`. Програма встановиться і відкриється сама.
3. Натисніть **Sign in to GitHub.com**. Відкриється браузер: увійдіть в обліковий запис **yarikhash-cyber** і натисніть **Authorize desktop**. Браузер поверне вас у програму.
4. На кроці **Configure Git** залиште ім'я й пошту як є і натисніть **Finish**.

## 3. Завантажити проєкт

1. У GitHub Desktop натисніть меню **File → Clone repository…**
2. На вкладці **GitHub.com** оберіть **yarikhash-cyber/AllinFarm**.
3. У полі **Local path** залиште `C:\Users\ysroslav\Documents\GitHub\AllinFarm`.
4. Натисніть **Clone** і дочекайтеся кінця завантаження.

## 4. Запустити

1. Переконайтеся, що Docker Desktop відкритий і внизу зліва написано **Engine running**.
2. У GitHub Desktop натисніть меню **Repository → Show in Explorer**. Відкриється папка проєкту.
3. Двічі клацніть файл **start.cmd**.
4. Якщо Windows покаже «Windows захистив ваш ПК», натисніть **Докладніше**, потім **Однаково запустити**.
5. Перший запуск триває кілька хвилин: Docker завантажує і збирає все потрібне. Наступні запуски значно швидші.
6. Коли все готово, браузер сам відкриє <http://localhost:8080>. Ви побачите сторінку «Каркас працює», і в усіх рядках буде «працює».
7. Напишіть Claude «запустилось». Якщо щось пішло не так, скопіюйте текст із чорного вікна і надішліть Claude.

## Щодня

- **Оновити до нової версії:** у GitHub Desktop натисніть **Fetch origin**. Якщо з'явиться кнопка **Pull origin**, натисніть її. Потім двічі клацніть `start.cmd`.
- **Зупинити:** двічі клацніть `stop.cmd`. Дані в базі зберігаються до наступного запуску.
- **Пошта для розробки:** <http://localhost:8025>. Сюди потрапляють усі листи, які надсилає система; назовні вони не йдуть.

## Якщо щось не так

| Що бачите | Що робити |
| --- | --- |
| «Docker Desktop не запущений» | Відкрийте Docker Desktop з меню Пуск, дочекайтеся **Engine running** і запустіть `start.cmd` ще раз |
| Docker пише про віртуалізацію (Virtualization support not detected) | Віртуалізацію треба увімкнути в BIOS. Напишіть Claude модель комп'ютера, і він дасть кроки |
| Сторінка не відкривається, хоча вікно пише «AllinFarm працює» | Зачекайте хвилину й оновіть сторінку. Якщо не допомогло, надішліть Claude текст із чорного вікна |
| Помилка про порт 8080, 8025, 8000 або 54320 | Ці порти зайняті іншою програмою. Напишіть Claude, він змінить порти |
| Помилка про сертифікат (certificate) під час першого запуску | Мережа підприємства перевіряє з'єднання. Напишіть Claude: для цього є окреме налаштування |
