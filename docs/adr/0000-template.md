# NNNN. Назва рішення

- Статус: пропозиція | прийнято | замінено ADR-NNNN
- Крок плану: N

## Контекст

Що змушує приймати рішення. Факти й обмеження.

## Рішення

Що вирішили, одним-двома абзацами.

## Наслідки
