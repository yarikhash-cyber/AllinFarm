# 0001. Назва і ліцензії

- Статус: прийнято власником проєкту
- Крок плану: 1

## Контекст

Проєкт відкритий. Код має лишатися відкритим і тоді, коли хтось запускає його як сервіс. Вікі має бути відкритою для читання і повторного використання. Власник хоче мати можливість платної хмарної версії.

## Рішення

1. Назва продукту: **AllinFarm**.
2. Код: **GNU AGPL-3.0-or-later** (`LICENSE`). Хто запускає змінений код як сервіс, мусить відкрити зміни.
3. Вікі в `knowledge/`: **CC BY-SA 4.0** (`knowledge/LICENSE`). Похідні бази знань лишаються відкритими.
4. Внески сторонніх людей: за **CLA** (`CLA.md`). CLA зберігає за власником право поширювати код і під іншою ліцензією, наприклад у платній хмарній версії.

## Наслідки

- Залежності мають бути сумісні з AGPL: дозволені MIT, BSD, Apache-2.0, ISC, MPL-2.0, LGPL, GPL-3.0, AGPL-3.0 та подібні. Пропрієтарні й несумісні ліцензії заборонені.
- Дані в ядрі лише під CC BY, CC0 або суспільним надбанням.
- Текст CLA перевіряє юрист до першого зовнішнього внеску.

## Як перевіряється

`scripts/check_licenses.py` у CI перевіряє ліцензії всіх залежностей Python і JavaScript за списком дозволених.
