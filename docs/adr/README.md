# Рішення (ADR)

ADR (Architecture Decision Record) — короткий запис одного архітектурного рішення: що вирішили, чому і що з цього випливає. Рішення записується в тому самому pull request, де воно стає кодом, і тримається тестом або перевіркою в CI.

Рішення не переписуються. Якщо рішення змінюється, пишеться новий ADR, а старий отримує статус «замінено ADR-NNNN».
